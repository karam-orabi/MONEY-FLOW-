# Security Policy

## Reporting a Security Issue

If you discover a potential security issue affecting MONEY-FLOW, please report it privately to the project maintainer rather than publicly disclosing the issue before it can be reviewed.

Please include:

- A clear description of the issue.
- The affected version.
- Steps required to reproduce the issue, if applicable.
- Any relevant screenshots or technical information.

## Supported Versions

The latest published release is the primary version considered for security-related review.

## Important Note

MONEY-FLOW is provided as a personal finance management application.

Users should keep regular backups of important information and install application updates only from the official project release channels.
